# Relay for macOS

Downloads only. This repository holds Relay's released builds; there is no
source code here.

## Install

1. Open [the latest release](https://github.com/jasonbrew-afk/relay-releases/releases/latest).
2. Download `Relay-<version>.dmg`, open it and drag Relay to Applications.

Every build is signed with a Developer ID and notarized by Apple, so it opens
with a double-click. Relay needs macOS 26 or later on Apple silicon.

## Updates

Relay checks this repository from Settings > About and installs new releases
itself. No GitHub account or token is needed.

Each release also carries a `.sha256` file for every download.
